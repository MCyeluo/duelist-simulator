# 牌佬模拟器

基于游戏王OCG原作背景的网页文字模拟器游戏。单文件HTML，下载即可玩，支持全平台响应式适配。

## 游戏特色

- 🎴 **卡片收集系统**：收集怪兽、魔法、陷阱、额外卡组、特殊卡片，组建你的专属卡组
- ⚔️ **决斗系统**：快速决斗、大师决斗、黑暗决斗三种模式，牌力=生命值实时对战
- 🏆 **比赛系统**：参加卡店比赛和官方赛事，赢取稀有卡片和决斗点
- 👥 **角色互动**：与原作角色互动，提升好感度，获得多挡位赠礼和挑战
- 🎲 **随机事件**：在童实野市、精灵界、黑暗领域等地点触发随机事件
- 🌟 **天赋系统**：按品质分为N/R/SR/UR，随机抽取6选2，隐藏天赋可通过成就解锁
- 🏅 **成就系统**：31种条件类型，支持多条件AND/OR逻辑，允许无条件成就
- 📊 **牌力系统**：根据卡组和属性实时计算牌力，决斗中实时变化
- 📖 **新手引导**：9步引导+演示页面，帮助新玩家快速上手
- 🏠 **主菜单系统**：开始新游戏、继续游戏、新手引导，游戏中可随时返回主菜单自动存档
- ✨ **卡片获得弹窗**：每张卡片单独弹窗显示详细信息，增强收集实感
- 🎭 **个性化体验**：自定义决斗者名字、称号、个性签名，个人主页查看全部数据
- 📋 **任务系统**：引导/主线/支线/隐藏四类任务，推进剧情和世界观，奖励手动领取
- 🔮 **隐藏天赋**：通过成就解锁隐藏天赋，跨存档保存
- 🎴 **系列卡组**：同系列卡15张以上触发系列标签，获得额外加成
- 💎 **卡片分解与共鸣**：分解多余卡片获得卡点，强化卡组共鸣提升主属性
- 🌌 **精灵力系统**：0-12星，每星+10%牌力，4星解锁精灵界地点
- ✨ **卡灵觉醒系统**：SR及以上卡牌可觉醒，觉醒后属性倍率大幅提升
- 🌑 **黑暗领域**：完成指定事件解锁，只能进行黑暗决斗，寿命赌注
- 🎁 **兑换码系统**：个人主页入口，可发放各种奖励，方便调试和活动
- 🏷️ **特殊卡片**：仅事件获取，不加入卡池，不可加入卡组，但提供属性加成

## 游戏规则

- 初始年龄18岁，每触发一次事件消耗7天（精灵界事件消耗1天），365天=1岁
- 正常游戏25岁结束（时空模拟器只能模拟7年），黑暗决斗失败扣除寿命，年龄达25岁直接结束
- 主卡组最少20张（快速决斗）/ 40张（大师决斗），最多60张
- 额外卡组最多15张
- 同名卡最多投入3张
- 决斗和比赛不消耗时间，只有触发事件才推进时间
- 主属性（检索/展开/干扰/抗性/压制）受卡组、天赋、成就、共鸣、卡灵觉醒影响
- 副属性（强度/魂度/掏度/熟练度/情报力）影响决斗判定和事件触发
- 精灵力0-12星，每星+10%战斗中牌力，4星解锁精灵界
- 卡灵觉醒：SR×5、UR×10、SP×100倍率，天赋「人人如龙」可解锁全卡牌觉醒并提升倍率

## 开发工具

`dev-tool.html` 统一可视化开发工具，无需代码交互即可编辑所有游戏数据：

- **支持14种数据类型编辑**：卡片、天赋、成就、任务、对手、决斗配置、核心配置、地点、角色、比赛、事件、兑换码等
- **支持导入游戏本体HTML，编辑后导出完整HTML文件**
- **卡片编辑器**：主属性/次属性滑块、稀有度/类型/系列选择、卡灵觉醒配置、特殊卡片标记、种类筛选和ID查询
- **天赋编辑器**：品质分类（N/R/SR/UR）、隐藏天赋、20+种可定义特殊效果、卡片属性加成范围限定、解锁成就配置
- **成就编辑器**：31种条件类型、多条件AND/OR逻辑、允许无条件成就、奖励配置
- **任务编辑器**：4种任务类型、多条件编辑、解锁成就/决斗模式/精灵力/觉醒碎片奖励
- **对手编辑器**：按类型分类支持自定义类型、特殊标签可被事件/比赛单独调用、寿命奖励配置
- **决斗配置编辑器**：多模式独立配置（快速/大师/黑暗），支持后续扩展
- **核心数据编辑器**：NPC成长、卡片分解与共鸣、精灵力系统、卡灵觉醒系统
- **角色编辑器**：多挡位赠礼系统（卡片/天赋/属性/卡点/决斗点）、挑战牌力无上限
- **比赛编辑器**：决斗模式、级别、参赛要求与消耗、轮数、对手牌力、奖励池
- **事件编辑器**：20+种效果类型（含解锁天赋/成就/地点、触发决斗、增加寿命等）、winEffects决斗胜利后额外效果
- **兑换码编辑器**：各种奖励类型配置、奖励卡片复选框勾选、多个属性加成可增删

## 技术栈

- 纯 HTML + CSS + JavaScript 单文件应用
- 无外部依赖，无需构建工具
- 响应式设计，支持手机、平板、电脑访问
- 本地存档（localStorage），键名 `duelist_sim_save`
- 卡片ID命名规则：怪兽m+3位(m001)、魔法s+3位、陷阱t+3位、额外e+3位、特殊sp+3位
- 数据区域标记：`/* === GAME_DATA_START === ... */` 和 `/* === GAME_DATA_END === ... */`

## 决斗机制

- 牌力=生命值，双方牌力实时变化，先归零者败
- 每回合双方交互：
  - **检索/展开**：影响己方牌力增长（熟练度影响展开和检索）
  - **干扰**：影响对方牌力增长（情报力影响干扰和压制）
  - **抗性**：减免对方干扰（情报力影响抗性）
  - **压制**：直接降低对方牌力
- **魂度和掏度**：影响对局中幸运事件触发
- **强度**：影响己方牌力增长和抗性强度
- **精灵力**：每星+10%战斗中牌力
- **卡灵觉醒**：觉醒卡牌属性倍率提升，大幅增加牌力
- 快速决斗默认30回合，大师决斗默认60回合，黑暗决斗回合数可配置
- 赌卡决斗：失败会随机失去卡组一张牌

## 牌力计算公式

```
有效展开 = 展开 + 熟练度 × 0.5
有效干扰 = 干扰 + 熟练度 × 0.5
有效抗性 = 抗性 + 情报力 × 0.5
有效压制 = 压制 + 情报力 × 0.5

牌力 = 检索 × 1.0
     + 有效展开 × 1.2
     + 有效干扰 × 1.0
     + 有效抗性 × 0.8
     + 有效压制 × 1.1
     + 强度 × 2.0
     + 魂度 × 0.5
     + 掏度 × 1.5
```

战斗中牌力 = 基础牌力 × (1 + 精灵力星级 × 0.1) × 系列卡组加成 × 其他加成

## 背景故事

你来自未来已经被毁灭的新童实野市，为了发现世界毁灭的真相，你利用来自未来的科技【时空模拟器】，回到了过去的童实野市。机器的能力只能够模拟7年时间。你将一边以决斗王为目标，一边寻找未来被毁灭的真相而努力。殊不知，这个世界也因为你的到来，发生了与众不同的变化...

基于游戏王OCG原作（不含同人衍生），地点为童实野市。
