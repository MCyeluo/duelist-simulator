# 牌佬模拟器

基于游戏王OCG原作背景的网页文字模拟器游戏。

## 游戏特色

- 🎴 **卡片收集系统**：收集怪兽、魔法、陷阱、额外卡组卡片，组建你的专属卡组
- ⚔️ **决斗系统**：快速决斗、大师决斗、赌卡决斗，多种决斗模式，牌力=生命值实时对战
- 🏆 **比赛系统**：参加卡店比赛和官方赛事，赢取稀有卡片
- 👥 **角色互动**：与原作角色互动，提升好感度，获得赠礼和挑战
- 🎲 **随机事件**：在童实野市的各个地点触发随机事件
- 🌟 **天赋系统**：按品质分为N/R/SR/UR，选择天赋影响游戏开局和发展
- 🏅 **成就系统**：解锁成就，获得属性加成和隐藏天赋
- 📊 **牌力系统**：根据卡组和属性实时计算牌力
- 📖 **新手引导**：9步引导+演示页面，帮助新玩家快速上手
- 🏠 **主菜单系统**：开始新游戏、继续游戏、新手引导，游戏中可随时返回主菜单
- ✨ **卡片获得弹窗**：每张卡片单独弹窗显示详细信息，增强收集实感
- 🎭 **个性化体验**：自定义决斗者名字、称号、个性签名，个人主页查看全部数据
- 📋 **任务系统**：23个任务（引导/主线/支线/隐藏），推进剧情和世界观
- 🔮 **隐藏天赋**：通过成就解锁隐藏天赋，跨存档保存
- 🎴 **系列卡组**：同系列卡15张以上触发系列标签，获得额外加成
- 💎 **卡片分解与共鸣**：分解多余卡片获得卡点，强化卡组共鸣提升主属性

## 游戏规则

- 初始年龄18岁，每触发一次事件消耗7天，365天=1岁，30岁游戏结束
- 主卡组最少20张（快速决斗）/ 40张（大师决斗），最多60张
- 额外卡组最多15张
- 同名卡最多投入3张
- 决斗和比赛不消耗时间，只有触发事件才推进时间
- 主属性（检索/展开/干扰/抗性/压制）受卡组、天赋、成就、共鸣影响
- 副属性（强度/魂度/掏度/熟练度/情报力）影响决斗判定和事件触发

## 如何运行

直接用浏览器打开 `duelist-simulator.html` 即可游玩，无需安装任何依赖。

## 文件说明

- `duelist-simulator.html`：游戏主程序（单文件，数据已内嵌）
- `dev-tool.html`：统一可视化开发工具，支持编辑卡片、天赋、成就、任务、事件、角色、比赛、决斗配置等数据
- `牌力计算器.html`：牌力计算公式计算器 + 对局模拟
- `游戏本体版本更新日志.html`：游戏本体版本更新日志
- `开发工具版本更新日志.html`：开发工具版本更新日志
- `index.html`：早期实验品（命运轮回录人生模拟器，非当前主线）

## 开发工具

- `dev-tool.html`：统一可视化开发工具
  - 支持10种数据类型编辑：卡片、天赋、成就、任务、对手、决斗配置、地点、角色、比赛、事件
  - 支持导入游戏本体HTML，编辑后导出完整HTML文件
  - 天赋编辑器：品质分类、隐藏天赋、20+种可定义特殊效果、卡片属性加成范围限定
  - 任务编辑器：4种任务类型、20种完成条件、6种奖励类型
  - 角色编辑器：多挡位赠礼系统（卡片/天赋/属性/卡点/决斗点）
  - 比赛编辑器：决斗模式、级别、参赛要求、轮数、对手牌力、奖励池
  - 事件编辑器：19种效果类型（含解锁天赋、触发决斗等）

## 技术栈

- 纯 HTML + CSS + JavaScript 单文件应用
- 无外部依赖，无需构建工具
- 响应式设计，支持手机和电脑访问
- 本地存档（localStorage）
- 卡片ID命名规则：怪兽m+3位(m001)、魔法s+3位、陷阱t+3位、额外e+3位

## 决斗机制

- 牌力=生命值，双方牌力实时变化，先归零者败
- 每回合双方交互：
  - 检索/展开：影响己方牌力增长
  - 干扰：影响对方牌力增长
  - 抗性：减免对方干扰
  - 压制：直接降低对方牌力
- 魂度和掏度影响对局中幸运事件触发
- 强度影响己方牌力增长和抗性强度
- 熟练度影响展开和检索，情报力影响干扰和压制
- 快速决斗默认30回合，大师决斗默认60回合
