# 牌佬模拟器 v4.0

基于游戏王OCG原作背景的网页文字模拟器游戏。单文件HTML，下载即可玩，支持全平台响应式适配。

## 游戏特色

- 🎴 **卡片收集系统**：收集怪兽、魔法、陷阱、额外卡组、特殊卡片，组建你的专属卡组
- ⚔️ **决斗系统（差值结算制）**：快速决斗、大师决斗、黑暗决斗三种模式，双方产生值差值结算
- 🏆 **比赛系统**：参加卡店比赛和官方赛事，赢取稀有卡片和决斗点
- 👥 **角色互动**：与原作角色互动，提升好感度，获得多挡位赠礼和挑战
- 🎲 **随机事件**：在童实野市、精灵界、黑暗领域等地点触发随机事件
- 🌟 **天赋系统**：按品质分为N/R/SR/UR，随机抽取6选2，隐藏天赋可通过成就解锁
- 🏅 **成就系统**：31种条件类型，支持多条件AND/OR逻辑，允许无条件成就
- 📊 **牌力系统**：根据卡组和属性实时计算牌力，决斗中实时变化
- 🎯 **玩家行为类型**：根据卡组配比自动分配（展开型/干扰型/防御型/均衡型），纯正面加成
- 🏷️ **副属性标签**：强度党/魂玩家/赌狗/打牌高手/情报玩家，可与行为类型叠加
- 🃏 **多系列卡组**：一张卡可拥有多个系列，15张以上激活，加成叠加
- 📖 **新手指南**：完整的从零开始指南，帮助新玩家快速上手
- 🏠 **主菜单系统**：开始新游戏、继续游戏、新手指南，游戏中可随时返回主菜单自动存档
- ✨ **卡片获得弹窗**：每张卡片单独弹窗显示详细信息，增强收集实感
- 🎭 **个性化体验**：自定义决斗者名字、称号、个性签名，个人主页查看全部数据
- 📋 **任务系统**：引导/主线/支线/隐藏四类任务，推进剧情和世界观，奖励手动领取
- 🔮 **隐藏天赋**：通过成就解锁隐藏天赋，跨存档保存
- 💎 **卡片分解与共鸣**：分解多余卡片获得卡点，强化卡组共鸣提升主属性
- 🌌 **精灵力系统**：0-12星，每星+10%牌力，4星解锁精灵界地点
- ✨ **卡灵觉醒系统**：SR及以上卡牌可觉醒，觉醒后属性倍率大幅提升
- 🌑 **黑暗领域**：完成指定事件解锁，只能进行黑暗决斗，寿命赌注
- 🎁 **兑换码系统**：个人主页入口，可发放各种奖励，方便调试和活动
- 🏷️ **特殊卡片**：仅事件获取，不加入卡池，不可加入卡组，但提供属性加成
- 💾 **存读档系统**：3个存档槽位+标识码导出导入，跨设备共享存档

## 游戏规则

- 初始年龄18岁，每触发一次事件消耗7天（精灵界事件消耗1天），365天=1岁
- 正常游戏25岁结束（时空模拟器只能模拟7年），黑暗决斗失败扣除寿命，年龄达25岁直接结束
- 主卡组最少20张（快速决斗）/ 40张（大师决斗），最多60张
- 额外卡组最多15张
- 同名卡最多投入3张
- 决斗和比赛不消耗时间，只有触发事件才推进时间
- 主属性（检索/展开/干扰/抗性/压制）受卡组、天赋、成就、共鸣、卡灵觉醒影响
- 副属性（强度/魂度/掏度/熟练度/情报力）影响决斗判定和事件触发
- 精灵力0-12星，每星+10%战斗中牌力，4星解锁精灵界
- 卡灵觉醒：SR×5、UR×10、SP×100倍率，天赋「人人如龙」可解锁全卡牌觉醒并提升倍率

## 决斗机制（v4.0差值结算制）

### 核心流程
- **玩家回合**：检索+展开产生本回合牌力值，受展开成功率判定（完美×2.0/常规×1.0/失败×0.3）
- **对手回合**：对方产生牌力，受玩家干扰（小幅削弱检索/展开，上限40%）和压制（大幅削弱展开，上限60%）影响
- **差值结算**：双方一回合产生值之差转化为牌力削减，diff>0对手扣血，diff<0玩家扣血
- **胜负判定**：牌力归零即败，同时归零时剩余牌力高者胜，回合耗尽时剩余牌力高者胜

### 玩家行为类型
根据卡组主属性配比自动分配，纯正面加成：
- **展开型**：展开占比≥25%且最高 → 展开+8%
- **干扰型**：干扰+压制占比≥35% → 干扰+8%、压制+8%
- **防御型**：抗性占比≥25%且最高 → 抗性+10%
- **均衡型**：各属性较平均 → 全属性+3%

### 副属性标签
根据副属性占比自动获得（占比≥35%触发），可与行为类型叠加：
- **强度党**：牌力增长+5%，抗性+3%
- **魂玩家**：战斗事件效果+10%
- **赌狗**：幸运事件触发率+5%
- **打牌高手**：完美展开+3%，常规展开+2%
- **情报玩家**：干扰/压制效果+5%，抗性+3%

### 多系列卡组
卡片archetype字段用/分隔多个系列，每个系列15张以上激活，加成叠加（每个系列强度+5、魂度+5、掏度+5）。卡组显示多个系列标签，幸运事件概率38%+每系列3%。

## 牌力计算公式

```
有效展开 = 展开 + 熟练度 × 0.5
有效干扰 = 干扰 + 熟练度 × 0.5
有效抗性 = 抗性 + 情报力 × 0.5
有效压制 = 压制 + 情报力 × 0.5

牌力 = 检索 × 1.0
     + 有效展开 × 1.2
     + 有效干扰 × 1.0
     + 有效抗性 × 0.8
     + 有效压制 × 1.1
     + 强度 × 2.0
     + 魂度 × 0.5
     + 掏度 × 1.5
```

战斗中牌力 = 基础牌力 × (1 + 精灵力星级 × 0.1) × 系列卡组加成 × 其他加成

## 版本更新

- 兼容旧格式标识码导入

- 修复导入后只隐藏main-menu面板而不隐藏整个view-start视图导致上下分屏的问题

- 导入过程添加try-catch错误保护，防止单步出错导致整个页面卡死

**战斗系统全面重制（差值结算制）**
- 玩家回合：检索+展开产生本回合牌力值，受展开成功率判定（完美×2.0/常规×1.0/失败×0.3）

- 差值结算：双方一回合产生值之差转化为牌力削减

**对手AI增强**

## 技术栈

- 纯 HTML + CSS + JavaScript 单文件应用
- 无外部依赖，无需构建工具
- 响应式设计，支持手机、平板、电脑访问
- 本地存档（localStorage），键名 `duelist_sim_save`
- 卡片ID命名规则：怪兽m+3位(m001)、魔法s+3位、陷阱t+3位、额外e+3位、特殊sp+3位
