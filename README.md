# 牌佬模拟器

基于游戏王OCG原作背景的网页文字模拟器游戏。

## 游戏特色

- 🎴 **卡片收集系统**：收集怪兽、魔法、陷阱、额外卡组卡片，组建你的专属卡组
- ⚔️ **决斗系统**：快速决斗、大师决斗、赌卡决斗，多种决斗模式
- 🏆 **比赛系统**：参加卡店比赛和官方赛事，赢取稀有卡片
- 👥 **角色互动**：与原作角色互动，提升好感度，获得赠礼和挑战
- 🎲 **随机事件**：在童实野市的各个地点触发随机事件
- 🌟 **天赋系统**：选择天赋，影响游戏开局和发展
- 🏅 **成就系统**：解锁成就，获得属性加成和隐藏天赋
- 📊 **牌力系统**：根据卡组和属性实时计算牌力

## 游戏规则

- 初始年龄18岁，每触发一次事件消耗7天，365天=1岁，25岁游戏结束
- 主卡组最少20张（快速决斗）/ 40张（大师决斗），最多60张
- 额外卡组最多15张
- 同名卡最多投入3张
- 决斗和比赛不消耗时间，只有触发事件才推进时间

## 如何运行

直接用浏览器打开 `index.html` 即可游玩，无需安装任何依赖。

## 开发工具

- `dev-tool.html`：统一可视化开发工具，支持编辑卡片、天赋、成就、事件、角色、比赛等数据
- `牌力计算器.html`：牌力计算公式计算器

## 技术栈

- 纯 HTML + CSS + JavaScript 单文件应用
- 无外部依赖，无需构建工具
- 响应式设计，支持手机和电脑访问
- 本地存档（localStorage）

基于游戏王OCG原作（不含同人衍生），地点为童实野市。
